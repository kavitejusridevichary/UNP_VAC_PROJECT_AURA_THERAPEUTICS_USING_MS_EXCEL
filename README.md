# UNP_VAC_PROJECT_AURA_THERAPEUTICS_USING_MS_EXCEL

Project Description – Pharmaceutical Data Analytics

Developed a Pharmaceutical Data Analytics project using Microsoft Excel to analyse drug sales, distribution, territory performance, and marketing campaign effectiveness. Performed data preprocessing, including handling missing values, removing duplicates, correcting errors, outlier detection, and dummyfication. Created pivot tables and an interactive dashboard with charts. Applied Z-Test, T-Test, ANOVA, correlation, and linear regression to identify trends and understand relationships in the data.
